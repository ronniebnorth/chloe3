## Bugs fixed (worth knowing the pattern)

- **The 2-minute AudioContext recycler breaks anything that holds a context.** Chloe swaps `ctxRef` every 120 s (and the old one closes 3 s later). That (1) cut every ⏺ rec take at ~118 s: the recorder now lives in its own context, and each playback context bridges in via `MediaStreamDestination` (`rec.attach`, called from `getCtx`); (2) silenced the beat for ~2 min after each swap (`beatNext` stayed on the old clock): it now resets on a new `ac` (`beatAc`). **Any new feature that keeps audio-clock state must handle the swap.** Also: the orchestra and kit rebuild per context, and the recycler skips while a journey's ending fade runs.
- **`v=` is note volume.** I first used `?v=listen` for the view, which made every note NaN (silent line). It's `view=` now; old `?v=listen` still opens Listen; non-numeric `v` falls back to 0.7.
- `getKit` must not list `getOrCreateDelay` in its deps (defined later → TDZ crash).
