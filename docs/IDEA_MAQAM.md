# Idea: maqam / quarter tones — became Chloe4

This idea (2026-11-08) was built as **Chloe4**: pitch stored in cents, maqam
and dastgah on a 24-step grid, Turkish makam in 53 commas, Byzantine chant in
72 moria.

- Live: https://ronniebnorth.github.io/chloe4/
- Repo: https://github.com/ronniebnorth/chloe4
- Design history, sources and backlog: `docs/IDEA_MAQAM.md` in the Chloe4 repo
